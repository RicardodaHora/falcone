# Falcone Patrimonio Landing

Projeto estatico pronto para publicacao na Vercel.

## Arquivos incluidos

- `index.html`
- `landing.css`
- imagens usadas pela landing

## Publicar na Vercel

1. Entre nesta pasta:
   `C:\Users\ue_e-rsilva\OneDrive - TAP Air Portugal\Documents\LandingPage\MI\landing-vercel`
2. Inicialize o Git:
   `git init`
3. Envie para um repositorio novo no GitHub:
   `git add .`
   `git commit -m "landing page falcone"`
   `git branch -M main`
   `git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git`
   `git push -u origin main`
4. Na Vercel, importe esse repositorio como um novo projeto.

## Configuracao na Vercel

- Framework Preset: `Other`
- Build Command: vazio
- Output Directory: vazio
- Install Command: vazio

Como o projeto e estatico, a Vercel serve o `index.html` diretamente.
